📊 Retail Sales Performance Analysis
🔍 Project Overview

An end-to-end data analysis project on 10,000+ retail transactions to evaluate sales performance, profitability, customer segments, regional trends, discount impact, and shipping efficiency — using Microsoft Excel and Power BI.

🎯 Business Objectives
Identify top-performing product categories and underperforming ones
Understand how discounts affect profit margins
Analyse regional and customer segment performance
Track monthly revenue trends and shipping efficiency
Build an interactive dashboard for business decision-making
🛠️ Tools & Technologies
Tool	Purpose
Microsoft Excel	Data cleaning, Pivot Tables, KPI calculations
Power BI	Interactive dashboard, DAX measures
DAX	Custom KPI formulas, calculated columns
GitHub	Version control and project showcase
📁 Project Structure

└── screenshots/        # Dashboard screenshots
📈 Key Business Insights
#	Insight
1	Technology is the highest-grossing product category
2	Tables and Bookcases generate negative profitability despite decent sales volume
3	Heavy discounts (>30%) directly cause profit losses across all categories
4	The Consumer segment contributes the highest revenue share
5	West region leads in sales; South region has the lowest profitability
